# Marcora for Cursor

Marcora is the context layer for go-to-market teams: your positioning, brand voice, and product facts in one source of truth that your AI tools read from.

This plugin connects Cursor to Marcora's hosted MCP server at `https://mcp.marcora.ai/` and adds the Marcora Workflows skill, which teaches the agent which Marcora tool fits each job.

## Setup

1. Install the plugin.
2. Cursor opens a Marcora sign-in the first time a Marcora tool runs. Sign in with your Marcora account. No API key or variable is needed.
3. Ask Cursor to use Marcora, for example: "Using my Marcora brand voice, draft a launch email."

You need a Marcora account. Sign up at [marcora.ai](https://marcora.ai).
